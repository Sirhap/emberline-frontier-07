# 余烬防线：前线 07

Godot 4.7、1280×720。开阔地砖房里守左侧核心：100 秒准备 → 作战 → 清场 +50 废料，核心一侧掉奖励。第 1–10 波是可玩闭环。没有 5 波通关。

## 启动

1. 用 Godot 4.7 导入本目录的 `project.godot`。
2. 运行项目。
3. 开局 100 秒准备：摊位地上能看到货架，走近按 `E` 或直接点货架购买。点 8 个固定垫放塔。倒计时结束自动开战。

## 操作

- 左下虚拟摇杆或 `WASD` / 方向键：移动英雄。
- 右下虚拟键：攻击、跳跃、冲刺、交谈（键盘仍是 `J` / `K` / 空格 / `E`）。
- `Space`：冲刺（需先解锁）。
- `J` 或攻击按钮：当前武器开火。
- `Q` 或右下角武器槽：在两把已持有的武器间切换。
- `K`：短跳。
- `U`：升级当前选中的塔。
- HUD「出售」：按造价 60% 卖掉选中塔（无热键）。
- `Tab` 或 HUD 速度按钮：切换 1× / 2×。只加快刷怪间隔，不加快敌人移动。
- 点击固定垫：放下持塔，或用废料建造默认塔种。
- 点击已部署塔：选中并显示升级 / 出售。
- `F1` 或 `` ` ``：开发者模式（默认关）。键表见 `scripts/main.gd` 的 `DEV_CHEATS`，与 HUD overlay 同一份。

## 玩法

- 初始 300 废料、核心 10 点生命。核心归零才结束。
- 塔只能放在 8 个固定垫上，不是满地格子。脉冲 80 / 爆裂 110 / 霜钉 90，各升 3 级。出售只退造价的 60%（脉冲 48），不退升级费。
- 敌人默认走向核心。只有走进英雄 96px 才拉仇，144px 外 0.4 秒脱仇。贴着核心肉抗且正在仇恨时不漏怪。
- 三种塔：脉冲（单体）、爆裂（溅射）、霜钉（减速）。武器见 `WeaponCatalog`（开局剑，商店/掉落会换成图鉴里的枪、弓、杖、投掷物）；开发者模式 `[` / `]` 循环切换。
- 英雄 100 血，被打死 4 秒后在核心附近复活并回 40 血。
- 清波写入 `user://run.json`；核心失守删档并开新局。

## 入口—核心约定

开阔地砖房：敌军从右侧宽口涌入，走向左侧核心 `(154, 336)`。塔绕行不封路。`main.gd` 的 `get_route_contract()` 与无头烟测会校验开阔布局。

## 资产与结构

- `assets/generated/`：战场、核心、三种塔、敌人、投射物、拾取物和界面图标。
- `assets/hero/`：英雄帧；运行时由 XSXB actor 播放。
- `scripts/wave_director.gd`、`shop.gd`、`weapon_catalog.gd`：波次、商店和武器数值。
- `scripts/main.gd`：场景编排、8 垫、弹池、存档、开发者键表。
- `scripts/hero.gd`：移动、近战、远程、冲刺、倒地复活。跳跃高度 32px。
- `scripts/hud.gd`：中文状态栏、商店、技能、结束结算、开发者面板。
- `AGENTS.md` / `CLAUDE.md`：给开发者模型的项目记忆，两份必须相同。
