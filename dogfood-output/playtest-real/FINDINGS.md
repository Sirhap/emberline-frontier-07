## P0

### P0-1 战败无结算，直接甩回家园
- **现象**: AppRoot 开战路径下，核心失守/复活耗尽后只有短暂状态，立刻切回家园，无「阵亡/失守」结算层、无重开按钮，像闪退。
- **复现**:
  1. 冷启动进角色选择，点「已出战」进家园
  2. 「开始远征」进入战斗
  3. 故意让核心掉到 0，或把英雄倒地耗尽复活
  4. 观察是否出现结算 Overlay；对照是否瞬间回到家园
- **证据**: 代码 `main.gd` `_end_run`（`_launch_configured` 时跳过 `show_end_screen`）+ `app_root.gd` `_on_run_finished`→`_show_home`；实机截图 `09b-defeat-moment.webp`（核心 0/10 +「核心过载/水晶崩解」、无结算 Overlay）→ `09-defeat-home.webp`（瞬间回家园，仅「开始远征」）
- **代码摩擦底稿**: `CODE_FRICTION.md` P0-1

### P0-2 选完角色后无法再换人
- **现象**: 冷启动选人一次后，家园只有「开始远征/继续远征」，无「换角色/角色选择」入口；想试另一英雄只能清档/重装。
- **复现**:
  1. 选「影刃刺客」→「已出战」进家园（见图 `05-home-hub.webp`）
  2. 打完或退出回家园后，找换人入口 → 没有
  3. 再「开始远征」仍是上次 `last_selected_hero`
- **证据**: `05-home-hub.webp`（仅开始/继续）；选人入口仅冷启动见 `01-char-details-scale.webp`
- **代码摩擦底稿**: `CODE_FRICTION.md` P0-2

## P1

### P1-1 确认进家园按钮文案是「已出战」（像状态不是动作）
- **现象**: 玩家在选人屏找「确认/进入」；卡片底部「已出战」读起来像已完成状态，易犹豫或点不着。
- **复现**: 打开角色选择 → 看选中卡底部三钮「详细/皮肤/已出战」→ 无全局「进入家园」
- **证据**: `01-char-details-scale.webp`, `03-locked-slot-feedback.webp`

### P1-2 刺客立绘相对骑士过小
- **现象**: 同排「余烬骑士」与「影刃刺客」体型差过大，刺客像未缩放好的素材。
- **复现**: 角色选择对比两张卡立绘
- **证据**: `01-char-details-scale.webp`, `02-skin-modal-scale.webp`

### P1-3 倍速「1x」难理解且体感异常
- **现象**: 右上「1x」无说明；连点后战斗节奏/受击不一定整体加速，玩家会以为坏了。
- **复现**: 开战 → 连点右上倍速 → 观察刷怪与操作体感
- **证据**: `07-speed.webp`, `06-battle-start.webp`

### P1-4 倒地/复活信息只有短 Toast，缺倒计时与库存展示
- **现象**: 倒地时玩家看不清还剩几次复活、多久起来；易误判已死透。
- **复现**: 开战被打死至倒地 → 看 HUD 是否有复活次数/计时（通常只有短暂字）
- **证据**: 本轮实机未稳定截到倒地帧；改时对照 `CODE_FRICTION.md` P1-4 + 战斗 HUD（`06`/`07`）。列为 P1，不强绑缺失图

### P1-5 无效存档时「开始远征」仍弹「覆盖当前远征？」
- **现象**: Continue 已隐藏且有「存档无效」，但 Start 仍按「有档」走覆盖确认，语义矛盾。
- **复现**: 放入无效 `user://run.json` → 家园见「存档无效」且无继续 → 点开始远征
- **证据**: 机制侧已验；本轮实机未重拍，改时对照家园 `05-home-hub.webp` + 既有 invalid-save 回归脚本
