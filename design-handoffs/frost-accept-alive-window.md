# 霜晶验收：T1.2 起 3 秒存活窗口

状态：tech manager + designer 已锁定
范围：霜晶技能施放后的短验收护盾，**不是**整段 8 秒持械无敌

## 流程

1. 选骑士 → 皮肤霜晶战士 → 家园「开始远征」
2. 进战场放技能 = **T0**
3. 输入解锁仍是 **≤1.2s**（`SKILL_INPUT_LOCK_CAP`，不改）
4. **T1.2** 起持械，并打开 **`FROST_ACCEPT_GUARD = 3.0` 秒**验收护盾

## 护盾（仅 3 秒，不是 form_left 神模式）

T0→T1.2 变身中，以及 T1.2 之后的 `FROST_ACCEPT_GUARD = 3.0` 秒：

- 英雄 `take_damage` 忽略（短 i-frame）
- 准备倒计时暂停、刷怪暂停
- 漏怪在核心 22px 处停住，不扣核
- 场上敌人减速、清一圈敌弹（不打一波斩杀）

3 秒后，即使仍持械（`form_left > 0`），英雄必须能死、核心必须能掉。直接套上 `frost_armed` 包 **不**给护盾，只有技能变身提交才给。

禁止把护盾绑到整段 `form_left > 0`。

## 三帧（必须在 T1.2 之后 3 秒内、活着且核心还在）

#27 的可读性不推翻：

- `LIVE-MOVE`：相对武装待机有位移（走/跑）
- `LIVE-JUMP`：腾空 / 收腿
- `LIVE-ATTACK`：横出冰剑挥砍

生命 > 0、核心未爆。倒地复活条或「核心失守」结算画面 = 验收失败证据。
