# 余烬防线：无尽塔防（元气骑士式）设计

日期：2026-08-17  
范围：在现有双路线战场上，把 5 波通关改成无尽塔防。保留地图、8 个固定塔位、英雄移动与近战剑。新增自动开波、商店、武器掉落、3 种塔、英雄血量与复活。

已确认选择：

- 方案 1：现有关卡上加系统，不重做地图
- 英雄按元气骑士打：换武器、放技能，塔补线
- 掉落 + 波次间商店
- 清波后 10 秒准备，到时自动开下一波
- 英雄有血，死后 4 秒在核心附近复活
- 第一版 3 种职能塔

## 1. 核心循环

一局没有胜利，只有失败：核心生命到 0 结束。结算最高波次、击杀数、存活时间。

四段循环：

1. **准备（10 秒）**  
   商店打开。可买塔、买武器、买技能、修核心。倒计时结束关店并开始下一波。开局先进入第 1 波准备，不自动刷怪。
2. **作战**  
   敌人沿现有上下两条路线前进。塔自动攻击。英雄用当前武器和冲刺补漏、打精英。击杀掉落废料和偶发武器。
3. **掉落**  
   小怪低概率掉基础武器。重装（精英）必掉一件武器。每 5 波 Boss 掉强化武器；若还没有冲刺，Boss 改为掉冲刺。
4. **清场**  
   本波计划刷完且场上没有存活敌人后，进入下一段 10 秒准备，商店刷新。

失败只看核心。英雄倒地不影响胜负，只让补防真空几秒。

资源只有一种：**废料（scrap）**。造塔、升级、商店、技能都花它。开局 300。

HUD 波次显示当前波数字，不再显示 `/ 5`。结束界面文案改为「核心失守」，正文写最高波次和击杀，不再出现「防线守住」。

## 2. 商店

只在准备阶段打开，作战中关闭。右侧滑出面板，倒计时和废料始终可见。时间到停止新交易；已经确认的购买立即生效。

每波货架 4 格：

| 格 | 内容 | 规则 |
|---|---|---|
| 1 | 塔 | 脉冲 / 爆裂 / 霜钉 随机一档。点选后进入「持塔」状态，再点空塔位放下。准备结束仍未放下则全额退款。 |
| 2 | 武器 | 手枪或霰弹。购买立刻替换当前武器，旧武器消失。 |
| 3 | 技能 / 回复 | 还没有冲刺则卖冲刺。已有冲刺则卖「立刻恢复英雄 40% 最大生命」。 |
| 4 | 核心维修 | 核心 +1 生命，上限 10（只能补回已损失的生命）。核心已满时本格改为「应急废料 +40」：点击领取一次后本格变空，同一准备阶段不能再领。 |

第 1 波货架固定，不随机：

1. 脉冲塔  
2. 手枪  
3. 冲刺  
4. 霜钉塔  

价格随波次上涨：`floor(base * (1.0 + 0.08 * (wave - 1)))`。`wave` 是即将开始的那一波。第 1 波用基础价。

基础价：

| 商品 | 基础价 |
|---|---|
| 脉冲塔 | 80 |
| 爆裂塔 | 110 |
| 霜钉塔 | 90 |
| 手枪 | 60 |
| 霰弹 | 75 |
| 冲刺 | 80 |
| 回血 40% | 50 |
| 核心 +1 | 100 |
| 应急废料 | 0（点击领取 +40 废料，每准备阶段最多一次） |

空塔位点击规则（准备和作战都有效）：

- 若处于「持塔」状态：在该位放下刚买的塔，不另扣费。持塔只存在于准备阶段。
- 否则：用废料直接建造当前默认塔种。默认塔种为脉冲，HUD 可切换为脉冲 / 爆裂 / 霜钉。
- 已占塔位：选中该塔，可用 `U` 或升级按钮升级。升级不进商店，作战中也可以升级。

准备阶段结束时，未放下的持塔必须退款，不能带进作战。

## 3. 武器、技能、英雄

同时只持一把武器。开局近战剑。换武器立即生效，旧武器不进背包。

面向：由最近一次水平移动决定。没有水平输入时保持上次面向。远程武器沿面向开火，不追踪敌人。

### 3.1 近战剑（开局）

- 键：`J` 或攻击按钮
- 沿用现有两刀连击，身前约 118 像素
- 每刀 46 伤害
- 完整连击节奏与现有 `hero.gd` 一致

### 3.2 手枪

- `J` 点射，沿面向飞弹
- 伤害 18，冷却 0.28 秒
- 弹速 700，最大飞行 420 像素后消失
- 单体，不穿透
- 不播放近战两刀动画；保持当前 idle/run，只出枪口闪光和弹体

### 3.3 霰弹

- `J` 一次打 5 发，扇形 ±22 度
- 每发 12 伤害，不穿透
- 冷却 0.70 秒
- 弹速 560；超过 180 像素后每发伤害降为 6，超过 240 像素消失
- 同一敌人可被多发命中
- 同样不播近战连击

Boss 掉落的强化武器：同类型，伤害 ×1.3 并向下取整（手枪 23，霰弹每发 15/8）。HUD 名称带「强化」。

### 3.4 冲刺

- 键：`K` 或 HUD 技能按钮
- 沿当前面向位移 180 像素，时长 0.22 秒
- 期间无敌 0.30 秒
- 冷却 6.0 秒
- 倒地期间不能冲刺
- 第一版只有这一个主动技能，没有第二技能栏

### 3.5 英雄生命

- 最大生命 100，开局满血
- 接触伤害：英雄与存活敌人距离 ≤ 26 像素时，每 0.60 秒结算一次（侦察 8，重装 16，Boss 28）
- 受伤后 0.40 秒受伤无敌，避免同一接触被连结算两次
- 头顶血条 + HUD 血量
- 生命到 0：倒地 4.0 秒，不能移动、攻击、冲刺
- 复活位置：核心受击点右侧约 80 像素（约 `(234, 336)`），生命设为 40
- 倒地期间塔和波次照常运行

### 3.6 地上掉落

- 侦察：8% 掉手枪或霰弹（各半）
- 重装：100% 掉手枪或霰弹
- Boss：掉强化手枪或强化霰弹；若英雄还没有冲刺，改为掉冲刺（捡起解锁技能，不替换武器）
- 拾取物在地上停留 20 秒后消失
- 英雄走到半径 28 像素内自动拾取
- 拾取武器立即替换；拾取冲刺只解锁技能

## 4. 三种塔

8 个固定塔位不变。每种塔升到 3 级。选中时画射程圈。

| 种类 | 作用 | 1 级 | 2 级 | 3 级 | 造价 | 升级费 |
|---|---|---|---|---|---|---|
| 脉冲 | 单体最高伤，沿用现有投射物 | 伤 24 / 射程 205 / 间隔 0.72 | 38 / 230 / 0.58 | 58 / 255 / 0.46 | 80 | 110 / 180 |
| 爆裂 | 命中后半径 78 溅射：主目标吃满额，其他目标吃子弹伤害的 55%（向下取整） | 16 / 190 / 0.90 | 24 / 210 / 0.76 | 36 / 230 / 0.64 | 110 | 140 / 210 |
| 霜钉 | 低伤，命中施加 40% 减速 1.5 秒；重复中减速刷新时长 | 10 / 200 / 0.80 | 14 / 220 / 0.68 | 20 / 240 / 0.56 | 90 | 120 / 190 |

减速：`move_speed * 0.60`，不叠加多次。Boss 减速改为 20%（系数 0.80）。

脉冲塔视觉沿用现有 `tower-lv1/2/3.png`。爆裂、霜钉用新生成像素图，三级各一张。

## 5. 波次与 Boss

没有 `MAX_WAVES`。准备倒计时结束时由波次导演开波，玩家不必再点「开始波次」。原按钮在准备期改为倒计时文本（「8 秒后开战」），作战中显示「第 N 波进行中」，不可点。`WaveDirector.start_wave()` 仍保留为测试入口：调用后立刻结束准备并开波。

生成公式（`n` 为当前波，从 1 起）：

- 小兵数量：`7 + n * 2`
- 侦察生命：`52 + n * 12`，移速：`57 + n * 4`，赏金：`16 + n * 3`
- 重装从第 2 波起，每第 4 个刷出单位是重装
- 重装生命：`112 + n * 22`，移速：`31 + n * 2`，赏金：`35 + n * 5`
- 刷怪间隔：`max(0.28, 0.68 - n * 0.045)`
- 上下两条路交替，与现在相同

每 5 波（5 / 10 / 15 …）在普通怪刷完后再刷 1 个 Boss：

- 生命：`420 + n * 55`
- 移速：`24 + n * 1.2`
- 赏金：`120 + n * 15`
- 走当前波下一条该轮到的路线
- 接触英雄伤害 28
- 抵达核心扣 2 点生命（普通怪仍扣 1）

清波奖励：每波清空 +50 废料，与现在相同，无尽后不取消。

倍速 1× / 2× 保留，作用于刷怪、敌人移动、塔冷却、投射物，不加速准备倒计时（准备始终按真实 10 秒，避免商店被倍速吃掉）。

## 6. 架构

现有 `main.gd` 继续做场景编排和输入入口，但波次、商店、武器开火从中拆出。不重写英雄移动、路线合同、XSXB 角色。

| 单元 | 职责 | 依赖 |
|---|---|---|
| `main.gd` | 建场景、点塔位、选塔升级、把输入转给英雄/商店/波次导演 | 下列模块 |
| `wave_director.gd` | 准备计时、自动开波、刷怪表、Boss、清场判定 | `main` 的生成/敌人列表 |
| `shop.gd` | 货架生成、购买、持塔、退款、价格缩放 | 废料、塔工厂、英雄武器 |
| `weapon_catalog.gd` | 剑/手枪/霰弹/强化变体的只读数值 | 无 |
| `hero.gd` | 移动、跳跃、近战、冲刺、生命、倒地复活；远程开火请求 | 武器目录、`main.spawn_hero_projectile` |
| `hero_projectile.gd` | 沿方向飞的英雄弹（手枪/霰弹），可带衰减 | 敌人 `take_damage(..., &"hero")` |
| `pickup.gd` | 地上武器/技能拾取 | 英雄位置 |
| `tower.gd` | 按 `kind` 应用数值；爆裂溅射、霜钉减速 | `main.find_enemy_in_range` |
| `enemy.gd` | 增加 `slow_until`、`core_damage`、接触伤害 | 无新硬依赖 |
| `hud.gd` | 无尽波次、准备倒计时、英雄血、技能 CD、商店面板、默认塔种 | 商店/导演信号 |

数据流：

```
WaveDirector --prep_started--> Shop.refresh() + Hud.show_shop()
WaveDirector --combat_started--> Shop.close() + spawn loop
Enemy.defeated --> scrap += reward, maybe spawn Pickup
Hero overlaps Pickup --> equip weapon or unlock dash
Shop.buy_tower --> hero holds tower blueprint --> click pad --> EmberTower
Shop.buy_weapon --> Hero.equip(weapon_id)
Core.health <= 0 --> Hud.show_end_screen(false, wave, kills)
```

`get_route_contract()` 保持现有字段和两条开放路线，烟测继续用它。

## 7. 错误与边界

- 废料不足：购买失败，状态栏提示，货架不变。
- 8 个塔位已满：持塔仍可买，但放不下；准备结束退款。直接点击空位时若无空位，提示「没有空余建造位」。
- 准备结束当帧：先结算退款，再关店，再开波。不允许关店后仍买入。
- 英雄倒地时忽略攻击、冲刺、拾取。
- 目标敌人在弹飞行中死亡：英雄弹继续飞到最大距离后消失，不报错；塔弹沿用现有「目标无效则销毁」。
- 商店刷新时上一波「持塔」必须已退款，不能把持塔带过波次。
- 核心维修不会超过 10。
- 倍速不影响准备倒计时。
- 结束界面出现后停止刷怪、停止商店、忽略建造，只留重开。


## 11. 成功标准

玩一局时：开局 10 秒内能买塔和手枪；之后无需再点「开始波次」；能用剑/枪/霰弹和冲刺补漏；塔分单体/群体/减速；核心破了才结束，并能看到自己撑到第几波。
